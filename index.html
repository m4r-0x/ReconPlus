⚠ Static showcase: this GitHub Pages site is a presentation page only. ReconPlus itself is a local Flask web application — GitHub Pages cannot host or run it. To use the tool, run it on your own machine (see Quick Start below). Never expose the local UI publicly, and only test systems you own or are explicitly authorized to test.

$ quick-start.sh

git clone https://github.com/m4r-0x/ReconPlus.git
cd ReconPlus

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

python -m pip install -r requirements.txt
python app.py

# open http://127.0.0.1:5000 in your browser

$ cat security-notice.md

  • Use this tool only on systems you own or are explicitly authorized to test.
  • ReconPlus executes external commands configured in its workflow.
  • Some steps perform active testing (vulnerability scanning, port discovery, directory fuzzing).
  • Keep the application bound to 127.0.0.1; do not expose it publicly.
  • Automated scan results require manual validation before any use.
